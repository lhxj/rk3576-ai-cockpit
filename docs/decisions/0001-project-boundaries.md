# ADR-0001：先建立可证实的单摄软件闭环

状态：本会话确定的架构约定；实现细节待各任务验收。

- 现有SDK不复制进主仓库；源码/模型/日志各自管理。
- Camera1线缆是局部阻塞，不停止Qt、单摄Media、Voice及AMP调查。
- 先保留厂商可用镜像，不为搭框架改变boot。
- AMP调查并行提前做，不拖到所有UI完成后才发现缺少RTOS交付。
- 所有硬件事实分“用户已验证”和“本轮重新实测”。
- 模拟LED/按键/蜂鸣器是产品展示范围调整，不冒充驱动验收。
- 单一物理板共享，Agent并行只能在host层面；设备测试串行。
- 默认不写死Codex模型，先确保账户/CLI可用，再选择成本策略。
