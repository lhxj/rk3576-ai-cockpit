# VAD resource observations

All measurements are engineering observations at default scheduler settings, not product performance commitments. Host `1.wav` two-utterance fixture: VAD processing about 37 ms over synthetic silence + audio twice; after-load PSS about 169 MB, after-fixture PSS about 172 MB in the observed run. RK3576 two-utterance fixture: VAD processing 637 ms; after-load RSS 166,408 KB / PSS 164,097 KB, after-fixture RSS 169,480 KB / PSS 166,481 KB, MemAvailable 2,913,492 KB at the final sample. The figures include Sherpa ASR and ONNX Runtime, not isolated VAD memory.

RK3576 5 s live VAD observation: ASR model load 9,084 ms; after-load RSS 170,040 KB / PSS 166,969 KB; after-run RSS 179,876 KB / PSS 174,251 KB, MemAvailable 2,904,932 KB. VAD processing time 499 ms, queue peak 4/100, overflow 0, XRUN 0, first partial after detected speech start 2,117 ms. No speech end/FINAL occurred within the run; end-to-final is unavailable (`-1`). CPU percentage, temperature peak and separate VAD PSS delta were not yet captured. These numbers cannot be used to claim combined camera/NPU/LLM resource fitness.

RK3576 200-utterance prerecorded fixture: VAD processing 55,638 ms, after-load RSS 178,964 KB / PSS 176,449 KB, after-run RSS 181,856 KB / PSS 178,828 KB, MemAvailable 2,898,536 KB at completion. A read-only `ps` sample during the run showed about 99.8% of one CPU and RSS 181,856 KB. Thermal zone 0 read 55.461°C during the run and 48.999°C afterward; these are samples, **not a measured peak**. Memory rose about 2.4 MB PSS from load to completion and requires longer observation before any leak conclusion. This run is a 200-utterance fixture loop, not 30-minute live microphone testing.

After adding separate model-load sampling, the board two-utterance fixture showed PSS 164,461 KB after ASR load and 165,793 KB after VAD load, an observed incremental **1,332 KB**. PSS after the two utterances was 168,173 KB. The C runtime's `ru_maxrss` high water was 205,428 KB during initialization; ordinary RSS at the final sample was 171,172 KB. CPU user time advanced from 8.814 s after both model loads to 11.479 s after the fixture; thermal zone 0 read 48.999°C after load and 49.922°C after recognition. These samples cannot isolate all allocator caches or prove steady-state behavior.

A later 20 s live capture with no controlled speech processed 320,000 frames. After-load RSS/PSS were 165,588/162,521 KB, after-run 171,756/166,351 KB; MemAvailable at completion was 2,912,036 KB. VAD processing totaled 2,893 ms, queue peak 1/100, overflow 0, XRUN 0. No speech start/end/FINAL occurred. This documents quiet capture behavior only.

Final 200-utterance resource sampling: ASR-load PSS 170,601 KB; after VAD load 172,953 KB (increment 2,352 KB in this run); sampled peak PSS 175,333 KB; sampled lowest MemAvailable 2,901,552 KB; sampled highest thermal zone 0 55.461°C. Process high-water RSS (`ru_maxrss`) 200,664 KB, final RSS/PSS 178,368/175,333 KB. CPU user time rose from 9,106 ms after both models loaded to 221,969 ms after 200 utterances; VAD `accept_samples` time summed to 48,771 ms. All 200 segments yielded FINAL with one load per model, ring peak 4800 frames and no sequence gap. Samples were taken every ten FINALs, so values are sampled extrema, not continuous hardware maxima. The PSS increase from after-load to completion was 2,380 KB; this short loop does not establish a long-term leak rate.
